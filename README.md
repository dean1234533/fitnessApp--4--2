# Full Fitness App: a trainer and client platform

**A fitness coaching app that connects personal trainers with their clients through dashboards, workouts, a food diary, meal ideas, a workout timer, and trainer–client chat. It is built with React and packaged for mobile with Capacitor.**

## Features

- **Two roles, trainer and client**, each with their own dashboard
- **Invite and link clients** to a trainer
- **Workouts page** with a built-in **workout timer**
- **Food diary** and a **meal idea generator**
- **Trainer–client chat**
- **Profiles** with avatar upload, plus a notepad
- Sign-in, password reset, and auth sync

---

## Tech stack

| Layer | Technology |
|---|---|
| Frontend | React, Vite, React Router |
| UI | Material UI, React Bootstrap, lucide-react |
| Backend | Supabase (auth, database, storage) and Firebase |
| Mobile | Capacitor / Ionic config |

## Getting started

```bash
git clone https://github.com/dean1234533/fitnessApp--4--2.git
cd fitnessApp--4--2
npm install
npm run dev
```

Add your Supabase and Firebase project credentials before running.
