Personal Training Client Management Web App

A secure, full-stack web application built for internal use within my personal training business. The app centralizes all essential coaching tools—allowing me to manage clients, programs, nutrition, communication, and notes in one place.

⸻

 Web App Key Features
	•	Secure login and registration with password recovery
	•	Personalized trainer dashboard
	•	Trainer–client relationships managed through user profiles
	•	Custom workout builder with detailed exercises
	•	Food diary for tracking client nutrition and meals
	•	Direct messaging with clients
	•	Notes section for reminders and key observations
	•	Form validation to prevent data entry errors
	•	Scroll-to-top button and mobile-friendly navigation

⸻

Tech Stack

Front End
	•	React
	•	JavaScript (ES6+)
	•	HTML5 & CSS3

Authentication
	•	Firebase Authentication
	•	Secure login, registration, and password reset

Back End & Database
	•	Supabase
	•	Backend services and PostgreSQL database
	•	Stores users, trainer–client relationships, workouts, food logs, notes, and chat messages
	•	Row-Level Security for data protection

⸻

 Design
	•	Clean interface with textured backgrounds
	•	Consistent red accent color across the app
	•	Large clickable cards for intuitive navigation
	•	Simple forms with clear descriptive labels
	•	Fully responsive and optimized for mobile and tablet use

⸻

 Security
	•	Encrypted password handling via Firebase
	•	Protected routes requiring authentication
	•	Automatic session management
	•	Secure backend access enforced through Supabase policies

⸻

Purpose

The purpose of this web app is to streamline client management for my personal training business. By consolidating workouts, nutrition tracking, communication, and notes into a single system, the app reduces administrative overhead and allows me to focus more on coaching and client results.
